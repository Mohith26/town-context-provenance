Assistant / Context provenance

Every claim, traced to its source and checked for freshness

Before an answer goes out, it is split into atomic claims. Each claim is checked against every source that mentions it across Slack, Linear, Notion and GitHub, so a newer Linear status beats an old Slack message, a merged PR beats an issue nobody updated, and two docs that disagree get flagged instead of picked from at random.
